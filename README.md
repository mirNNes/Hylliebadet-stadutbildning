# 🧼 Städutbildning – Hylliebadet

Detta är en webbaserad introduktionsutbildning för nyanställda på **Hylliebadet**.  
Utbildningen består av flera avsnitt där du får läsa instruktioner, se video och svara på frågor.  
När alla avsnitt är genomförda genereras ett certifikat som du kan spara eller screena.  

👉 **Starta utbildningen här:**  
[https://mirNNes.github.io/Hylliebadet-stadutbildning/](https://mirNNes.github.io/Hylliebadet-stadutbildning/)

---

## 📚 Innehåll i utbildningen
- Städrummet – rutiner och utrustning  
- Städinstruktion måndag (omklädningsrum 1 och 6)  
- Städinstruktion tisdag (gallerian, bastu, omklädningsrum 7)  
- Fler avsnitt läggs till vid behov
